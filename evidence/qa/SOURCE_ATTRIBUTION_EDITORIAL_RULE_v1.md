# Source Attribution Editorial Rule v1

Status: ACTIVE PRELAUNCH CONTROL
Date: 2026-09-17

## Purpose
Prevent repetitive source-name-first writing while preserving evidence accuracy on a health/YMYL-adjacent dental cost site.

## Core rule: answer first, source second
Procedure pages should normally begin with the scoped answer or price unit, then attribute the supporting source in the same paragraph or immediately after it.

Preferred pattern:
- `A current published U.S. benchmark for [procedure] is $X–$Y per [unit]. [Source] publishes that range...`

Avoid repetitive pattern:
- `[Source] reports...` as the opening construction across many pages.

## Source diversity rule
Do not rotate publishers merely for stylistic variety. Use each source only for claims it actually supports.

Preferred source roles:
- U.S. government/public-health and professional dental organizations: clinical definitions, safety, terminology, care-process facts.
- Recognized fee/cost datasets and major insurers: procedure price observations and plan mechanics when scope is explicit.
- Local insurer/provider examples: local examples only; never generalize nationally.
- Manufacturer sources: naming, trademark, device/concept attribution only unless stronger independent evidence supports broader claims.

## Synthesis rule
Multiple sources may appear in an opening only when their scopes are compatible and the synthesis does not manufacture a new range, average, inclusion rule, or national claim.

Never:
- merge the low value from one source with the high value from another;
- combine local and national figures into a synthetic national range;
- use a professional association as price evidence when it only supports clinical terminology;
- change or rotate a source simply to avoid repetition.

## Editorial QA
For each page, check:
1. Does the opening answer the user before naming the publisher?
2. Is every number tied to its original source, geography, unit and scope?
3. Are different sources doing different evidence jobs rather than being used decoratively?
4. Does the page avoid repeating the same source-name-first sentence structure used on neighboring pages?
5. Would removing the source name change the meaning of the claim? If yes, keep attribution close to the claim.

This rule applies to all new drafts and should be incorporated during cleanup of existing preview pages.
