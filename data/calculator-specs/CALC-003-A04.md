# CALC-003-A04 — All-on-4 Quote Normalizer Spec

Status: FROZEN FOR IMPLEMENTATION  
Page: DEN-012 `/all-on-4-dental-implants-cost/`  
Updated: 2026-09-16

## 1. Purpose

Normalize a user's written All-on-4 quote by explicit arch count and package inclusion scope while showing a clearly labeled published reference range.

This is not a clinical eligibility tool, treatment planner or provider quote generator.

## 2. Reference evidence

`SRC-DEN012-001` CareCredit:
- published 2026-04-24;
- 2024 Synchrony Average Procedural Cost Study conducted by ASQ360° across 50 states + DC;
- national average: $15,176;
- reported range: $11,640–$27,500.

Scope caveat:
- article context defines All-on-4 as replacement of all teeth in either the upper or lower jaw using four implants and a bridge;
- the price sentence itself does not independently state “per arch”;
- therefore the reference is shown as an All-on-4 procedure benchmark and must never be silently doubled or treated as a confirmed two-arch/full-mouth amount.

Package inclusions such as extraction, grafting, imaging, temporary bridge, final bridge and follow-up are not sufficiently explicit in the price block and default to UNKNOWN.

## 3. Inputs

- `quoted_total`: currency $0–$1,000,000.
- `arch_count`: required enum `1` or `2`; user must confirm the written quote explicitly covers that many arches.
- Package status fields:
  - implant placement
  - multi-unit/other abutments if stated
  - temporary/provisional bridge
  - final bridge/prosthesis
  - extractions
  - bone grafting
  - imaging/exam
  - sedation/anesthesia
  - follow-up/adjustment visits
  - other component
- Status enum: `included`, `separately_quoted`, `not_on_quote`, `unknown`.
- Optional amount for each separately quoted item.

Insurance:
- `none`
- `entered_estimate`
- `unknown`

If `entered_estimate`:
- insurer estimate amount
- same-scope confirmation

## 4. Logic

Use integer cents.

`entered_total = quoted_total + sum(entered separately_quoted amounts)`

`normalized_per_arch = entered_total / arch_count`

If fractional-cent division occurs, display as approximate.

Insurance logic matches CALC-003/CALC-001:
- none → insurer $0; patient estimate = entered_total
- entered estimate + same-scope confirmation + estimate <= total → subtract
- unknown or scope mismatch → patient estimate UNKNOWN

## 5. Reference display

Show a non-computational reference card:
- “CareCredit 2024-cost-study reference: $15,176 average; $11,640–$27,500 reported range for All-on-4 dental implants.”
- “Source context describes treatment of an upper OR lower jaw; confirm whether your own quote is for one arch or both arches.”
- “Published cost block does not establish that extraction, grafting, imaging, temporary bridge, final bridge or follow-up are all included.”

Reference values do not populate `quoted_total` and do not affect arithmetic.

## 6. Outputs

- Entered quote total.
- User-confirmed arch count.
- Approximate normalized per-arch amount.
- Package inclusion matrix.
- Unknown/missing component warnings.
- Conditional insurer contribution.
- Conditional patient estimate.
- CareCredit reference card and data-vintage note.
- Link to DEN-003 for generic full-mouth/full-arch comparison context.

## 7. Brand / clinical guardrails

`SRC-DEN012-002` Nobel Biocare may be used only for trademark/concept attribution.

Tool must not:
- say All-on-4 is superior or appropriate for the user;
- infer graft-free eligibility;
- decide implant positions or number beyond the branded concept description;
- infer treatment need;
- convert manufacturer claims into expected outcomes;
- call output an actual quote or coverage guarantee.

## 8. Package-scope behavior

If temporary or final bridge status is `unknown`, show a high-priority package warning.

If extraction/graft is `not_on_quote`, state only that the item is not listed; never imply it is unnecessary.

If arch_count cannot be confirmed from the written quote, do not calculate per-arch normalization.

## 9. Insurance methodology

No automatic coverage percentage. No automatic deductible/annual maximum/lifetime maximum.

Only a user-entered same-scope insurer estimate may reduce the displayed patient estimate.

## 10. Accessibility / privacy

- labels, fieldsets and legends;
- keyboard-only operation;
- focused error summary;
- live results;
- widths 320/390/768/1280/1920;
- no quote values stored, sent externally or serialized to URL absent future privacy approval.

## 11. Test matrix

1. Blank → invalid.
2. $15,000 quote, confirmed 1 arch → $15,000 per arch.
3. $30,000 quote, confirmed 2 arches → $15,000 per arch.
4. Arch count not confirmed → no per-arch result.
5. Unknown final bridge → total shown + high-priority warning.
6. Separate graft $1,500 → added only when user enters amount.
7. `not_on_quote` extraction → no amount added; no clinical inference.
8. Insurance none → patient estimate = entered total.
9. Insurance unknown → patient estimate UNKNOWN.
10. Same-scope insurer estimate valid → subtract.
11. Insurer estimate > total → invalid.
12. CareCredit reference card visible but does not alter total.
13. Reference range is never automatically doubled for two arches.
14. Manufacturer content never affects formula.
15. Reset clears state.
16. No storage/network/URL serialization.

## 12. Shared implementation

CALC-003-A04 should share the same tested arch-quote core as CALC-003. Page-specific configuration supplies labels, reference card and package fields. The core remains quote-input driven.
